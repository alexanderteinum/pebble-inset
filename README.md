# Inset

A minimal Pebble watchface, neatly inset from the edge.

![Inset screenshot](screenshot.png)

Uses the watch’s 12/24-hour setting and shows the date as `Jun 12`. Supports all Pebble models, with larger text on Emery and Gabbro. No configuration, animations, or network requests.

## Inspiration

Inset’s design is inspired by Simple, which was inspired by Blotch and Marked 2.

## Build & install

Requires the [Pebble SDK](https://developer.rebble.io/docs/).

```sh
pebble build
pebble install --cloudpebble
```
